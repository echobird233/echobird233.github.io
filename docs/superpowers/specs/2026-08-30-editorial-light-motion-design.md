# LCX 个人主页「编辑之光」动效设计规格

日期：2026-08-30  
状态：已获用户批准  
适用站点：luchunxiang.cn / echobird233.github.io

## 1. 设计目标

在不破坏现有学术档案式信息结构的前提下，增加明确的互动反馈和具有个人辨识度的动效。页面应继续像研究记录与个人档案，而不是演示文稿、营销落地页或卡片式作品集。

动效承担三项职责：

1. 帮助读者理解当前阅读位置；
2. 提示哪些内容可点击或可继续探索；
3. 通过「墨迹、聚光、抽线」形成统一的视觉记忆。

## 2. 参考范式与许可边界

本方案从以下公开项目提取设计范式，不整套复制第三方页面：

- [Athena Personal Academic Page](https://github.com/AaronZ345/Athena-personal-academic-page)：学术身份栏、研究优先的信息组织、响应式导航；MIT License。
- [al-folio](https://github.com/alshedivat/al-folio)：学术主页的内容密度、出版物与项目层次；MIT License。
- [Portfolio Starter](https://github.com/mullinsben/Portfolio-Starter)：无框架静态站点、进入动画、无障碍与 `prefers-reduced-motion` 范式；MIT License。
- [AOS](https://github.com/michalsnik/aos)：滚动进入动画的触发逻辑与一次性揭示范式；MIT License。
- [ScrollSpy](https://github.com/fsegurai/scrollspy)：固定目录根据阅读位置高亮的交互范式；MIT License。

正式实现采用项目自有的 CSS 和原生 JavaScript，不引入第三方运行时、CDN、框架或远程字体，也不复制受限模板的资产。

## 3. 已批准方向

用户选择 C2「编辑之光」。核心视觉语言为：

- 深色身份栏与暖白正文形成编辑杂志式对照；
- LCX 圆形标识使用墨水上升与虚线旋转反馈；
- 正文区域跟随鼠标产生低对比度暖色聚光；
- 链接通过细线从左向右展开；
- 研究与经历条目悬停时出现左侧墨迹线、轻微位移与极小角度倾斜；
- 页面载入使用短暂的深色 LCX 幕布；
- 正文章节进入视口时从轻微模糊、下移状态恢复清晰；
- 左栏显示阅读进度，并自动高亮当前章节。

## 4. 布局与信息结构

### 桌面端

- 左侧身份栏固定在浏览器左边缘，宽度约 260–270 px，高度为完整视口；
- 右侧正文居中，最大宽度约 800–820 px；
- 首页首屏保持文档比例，不能使用占满视口的巨型标题；
- 首页开头使用一条研究陈述，下面继续呈现个人简介、研究重点与相关兴趣；
- Research、Experience、Honors 保留当前按条目和时间组织的结构，不改成卡片网格。

### 移动端

- 身份栏变为页面顶部的深色身份区；
- 导航以两行或折叠菜单呈现；
- 正文恢复单栏；
- 关闭自定义光标、鼠标聚光、三维倾斜和持续旋转；
- 保留简短的进入动画和普通链接反馈。

## 5. 交互细节

### 5.1 页面载入

JavaScript 可用且用户没有开启减少动态效果时，显示 LCX 深色幕布，并在约 0.9–1.2 秒内向上揭开。幕布不得阻塞超过必要时间。

### 5.2 滚动揭示

使用 `IntersectionObserver` 为正文区块和列表条目添加一次性的可见状态。无 JavaScript 时内容默认可见，避免内容被永久隐藏。

### 5.3 当前章节与阅读进度

首页锚点导航使用 `IntersectionObserver` 更新活动链接；左栏右侧的细线根据页面滚动比例增长。子页面沿用页面级 `aria-current`，不伪造不存在的锚点。

### 5.4 鼠标响应

仅在支持精确指针、悬停且未开启减少动态效果的设备上启用：

- 暖色径向聚光；
- 小圆点与延迟圆环组成的自定义光标；
- 条目不超过约 ±1.5° 的轻微倾斜；
- 链接和条目悬停状态。

### 5.5 页面切换

同域内部页面链接可触发快速淡出或幕布回收，然后导航。页内锚点、外部链接、邮件链接、下载、打印按钮不触发页面切换动画。

## 6. 无障碍与性能

- 完整支持 `prefers-reduced-motion: reduce`，关闭幕布、持续动画、平滑滚动、聚光、自定义光标和倾斜；
- 保留键盘焦点轮廓，键盘操作不依赖鼠标状态；
- 不使用强制平滑滚动库；
- 不引入 Canvas、WebGL、GSAP、Lenis 或大型动画依赖；
- 动画主要修改 `transform` 和 `opacity`，避免频繁布局计算；
- 自定义光标不在触摸设备启用；
- 打印样式继续隐藏身份栏和全部装饰动效。

## 7. 内容与页面范围

统一应用于：

- 首页；
- Academic Research；
- Internship；
- CV；
- Notes；
- 404 页面。

首页研究陈述可改为「从运动估计出发，建立可靠且可复现的研究轨迹」，但不得夸大成果。论文草稿仍明确标注尚未投稿；公开 GitHub 链接继续保留，未公开项目不得编造仓库链接。

## 8. 验收标准

1. 桌面端左栏固定在浏览器左边缘，正文保持文档式比例；
2. 首页当前章节高亮与阅读进度随滚动变化；
3. 聚光、光标、条目反馈在桌面端有效；
4. 移动端无横向溢出，身份区与正文顺序正确；
5. 减少动态效果模式下所有内容立即可见；
6. 无 JavaScript 时页面内容仍可阅读和导航；
7. 所有现有内部页面和公开 GitHub 链接保持可用；
8. 打印 CV 不包含深色身份栏、光标或动画装饰。
