# 卢春翔个人主页：学术侧栏改版设计规格

## 1. 改版目标

将当前“大标题、全宽分节、大卡片”的展示型页面重构为适合长期维护的学术个人主页。新版应更像一份持续更新的学术档案或研究文档，而不是演示文稿、作品集封面或网页 PPT。

改版保留现有内容事实、隐私边界、GitHub Pages 部署方式、自定义域名和 SEO 基础配置，只重构视觉语言、信息层级与页面组件。第一版仍使用静态 HTML、CSS 和极少量 JavaScript，不引入 Jekyll、React、数据库或复杂构建流程。

## 2. 参考范式与设计取舍

结构参考以下公开学术主页范式，但不直接套用主题：

- Academic Pages 的作者侧栏与学术内容组织：<https://github.com/academicpages/academicpages.github.io>
- Minimal Mistakes 的 author profile + main content 双栏结构：<https://mmistakes.github.io/minimal-mistakes/docs/layouts/>
- al-folio 对研究、项目和简历内容的学术化表达：<https://github.com/alshedivat/al-folio>

用户已选择“经典学术主页”布局和“A2 温暖档案感”视觉。新版吸收作者侧栏、连续正文、研究条目和学术身份链接等成熟范式，同时保持现有纯静态网站的可控性。

明确取消以下旧版特征：

- 巨型姓名和宣传式首屏。
- 全宽章节幕、编号式展示章节和大面积色块。
- 大项目卡片、悬浮阴影、大按钮和数据海报。
- 为了视觉填充而重复同一信息。
- 不必要的滚动动画、轮播和复杂交互。

## 3. 全站布局

### 3.1 桌面端

页面主体采用左侧身份栏和右侧正文的双栏结构：

- 页面内容总宽度约 `980–1050px`，居中显示。
- 左侧栏宽约 `205–220px`，与右侧正文通过一条细竖线分隔。
- 右侧正文最大宽度约 `700–740px`，保持适合长文阅读的行长。
- 左侧栏使用 `position: sticky`，随页面滚动保持可见，但不使用覆盖正文的固定定位。
- 桌面端不设置顶部主导航；导航入口位于左侧栏底部。
- 页面背景使用统一暖灰纸张色，不再把各章节放入独立卡片或带阴影容器。

### 3.2 移动端

当视口宽度小于 `760px` 时：

- 左侧栏转换为页面顶部的紧凑身份区。
- 默认只显示 `LCX`、中英文姓名、学生身份和简要研究方向。
- 作者信息、ORCID、GitHub 和两个邮箱放入原生 `<details>` 可展开区域；在 JavaScript 失效时仍然可用。
- 页面导航通过简洁菜单显示，不使用横向滚动卡片。
- 研究条目的日期移动到标题上方，正文保持单列。
- 页面不得出现横向溢出。

## 4. 视觉语言

采用“A2 温暖档案感”：

- 页面背景：暖米灰 `#f7f4ed`。
- 左侧身份区：略深的暖灰 `#eee9df`。
- 主文字：深灰黑 `#282724`。
- 次级文字：暖灰褐 `#676057`。
- 链接与强调：克制的棕色 `#75543a`。
- 分隔线：低对比暖灰 `#c8beb0`。

排版规则：

- 中文标题与正文优先使用系统宋体/衬线字体栈，英文衬线使用 Georgia。
- 元信息、日期、导航和标签使用系统无衬线字体。
- 不依赖远程 Web Font；在中国大陆网络环境中仍应稳定显示。
- 首页最大标题约 `24–28px`，章节标题约 `17–20px`，正文约 `14–16px`；不再使用超过 `48px` 的展示字号。
- 视觉层级主要通过字号、字重、留白和细分隔线建立，而不是背景色块或阴影。

## 7. 子页面结构

### 7.1 学术研究页

沿用相同左栏。右侧顺序为：研究概述、时间线、当前两个子项目、早期项目。每个当前项目按“问题—方法—数据集—结果—证据边界—状态”组织。实验指标使用正文或普通表格，不做大数字海报。

### 7.2 实习经历页

沿用相同左栏。右侧顺序为：公司与岗位概述、ROS 2 项目、Pixi RISC-V 项目。每项按“问题—完成内容—结果—限制—GitHub”组织。QEMU 数据继续明确标注为模拟环境结果。

### 7.3 简历页

屏幕浏览时沿用身份栏。正文使用紧凑履历格式。打印或保存 PDF 时隐藏身份栏与导航，将简历正文扩展到纸张宽度；继续排除手机号、住址、身份证号、薪酬与协议敏感信息。

### 7.4 调研与笔记页

按年份排列文章标题、日期、摘要和少量标签，使用论文目录式纵向列表。没有文章卡片网格、封面图片墙或虚构占位文章。

### 7.5 404 页面

使用相同颜色和小字号文档风格，只保留简短错误说明和返回首页链接。

## 8. 组件与实现边界

全站复用以下职责清晰的组件样式：

- `site-shell`：控制桌面双栏与移动单栏。
- `profile-rail`：桌面身份栏。
- `mobile-identity`：移动端身份摘要与可展开作者信息。
- `document-section`：正文章节标题和间距。
- `dated-entry`：日期—内容条目。
- `nested-entry`：当前大创的两个子项目。
- `text-link`：统一外部和内部文本链接。

纯静态站点没有运行时数据流。所有公开内容直接保存在语义化 HTML 中，搜索引擎和无 JavaScript 环境均可读取。JavaScript 只负责移动端菜单，不负责隐藏核心内容。

## 9. 可访问性、SEO 与容错

- 保持 `lang="zh-CN"`、页面标题、description、canonical、Open Graph、sitemap、robots 和 CNAME 一致。
- 首页继续使用一个明确的 `<h1>`；左栏姓名不与正文标题争夺标题层级。
- 链接文字说明目的，不使用只有图标的链接。
- 键盘焦点必须清晰；颜色对比满足普通正文可读性。
- 外部链接使用 `target="_blank" rel="noopener noreferrer"`。
- 移动作者信息使用原生 `<details>`，脚本失败仍可展开。
- 添加 `Person` JSON-LD 结构化信息，只包含公开姓名、英文名、学校、ORCID 与 GitHub，不添加手机号、住址或邮箱。
- 远程字体、图片或脚本加载失败时，正文和导航仍正常显示。

## 10. 验收标准

1. `900px` 以上视口中，身份栏始终位于正文左侧，不会因容器宽度错误折叠到顶部。
2. `390px` 手机视口中，身份区位于顶部，正文单列且无横向溢出。
3. 首页没有巨型 Hero、大卡片网格、章节幕、大数字展示或装饰性阴影。
4. 首页首先显示 About、研究重点和相关兴趣，然后才进入研究、实习和荣誉条目。
5. 左栏包含 `LCX`、中英文姓名、作者名、学校、ORCID、GitHub 和两个邮箱。
6. 两篇论文均明确标注为“论文草稿，尚未投稿”。
7. 两个实习项目只出现在实习经历中，并链接到正确的 GitHub 仓库。
8. 研究页、实习页、简历页、笔记页和 404 页面共享同一布局与视觉语言。
9. 简历打印时隐藏导航和身份栏，且分页无明显断裂。
10. 所有内部页面、导航、外部链接、移动菜单、打印样式、sitemap 和 HTTPS 资源路径通过检查。

## 11. 范围外事项

本次不添加头像、深色模式、访客统计、评论、搜索、复杂动画、自动生成文章、数据库或 CMS。学生工作在用户提供可核实的职务与时间后再增加。
