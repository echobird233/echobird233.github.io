# 网站文案直接性重塑设计

## 目标

重写网站中的介绍、研究和项目文案，使句子直接、自然，以事实推动叙述。删除学业分数、否定式对照和只为预防质疑而存在的解释，同时保留理解研究方法与实验结果所需的范围信息。

## 修改范围

- 首页 `index.html`
- 公开简历 `resume.html`
- 学术研究详情页 `projects/academic-research.html`
- 实习详情页 `projects/internship.html`
- Notes 索引 `articles/index.html`

其他 HTML 页面只在发现同类问题时修改，不调整布局、动画或交互。

## 学业信息

- 删除总成绩 95.07、GPA 3.96 / 4.3、CET-6 492 等具体分数。
- 保留“大二学年专业第一、年级第一”。
- 不新增课程单科分数。

## 研究与实验数据

- 保留 HOTA、ADE、导航成功次数、覆盖率、帧数和运行耗时等实验数据。
- 保留数据集、实验环境、样本范围和模型状态。
- 技术限制改写为实验范围或条件，不使用辩解语气。

## 文案规则

1. 删除“不是……而是……”“并不是……”“不代表……”“不能据此……”等否定式对照。
2. 将必要边界改为直接事实，例如“实验在仿真环境中完成”“该指标记录机器人经过区域的覆盖情况”。
3. 删除只用于预防质疑的句子，包括隐私声明、成果免责声明和对读者可能误解的预先回应。
4. 保留投稿状态、代码公开状态和实验条件，因为这些信息直接描述项目现状。
5. 删除“这里”“本页”“需要分开理解”“当前限制”等编辑痕迹；标题可改为“实验范围”“实验条件”或直接并入正文。
6. 避免宣传语、抽象评价和连续三项式套话。优先使用主语明确的短句。
7. 不改变已经确认的奖项、日期、作者身份、投稿经历和项目结论。

## 页面处理

### 首页

- 简介删除具体成绩，保留排名。
- 将“理论与工程实践方面均有涉猎”等概括改成项目事实。
- 删除“这里只展示适合公开的信息”。

### CV

- 教育经历删除 GPA、总成绩和 CET-6 分数，保留排名。
- 删除隐私说明式结尾。
- 研究与实习条目只做语气压缩，不删除事实。

### 学术研究详情页

- VeloODE-MOT 的对比结果改为直接说明两种实验设置。
- 专家路由的开头改为“地图条件预测器的表现取决于场景”。
- 将“当前限制”改写为“实验范围”，直接列出对象、预测形式和评估内容。
- 删除智能会议项目的成果免责声明。
- 将 Banach 项目的投稿免责声明压缩为“当前材料为项目论文草稿”。
- 结尾只记录更新时间或数据版本，不再作防御性总结。

### 实习详情页

- 将“没有实现新的算法”改成实际工作内容。
- 覆盖率、合成视频、随机初始化模型等说明改为实验条件。
- 删除未做事项的长列表，只保留“仿真环境”这一必要条件。
- 删除页面底部隐私声明。

### Notes 索引

- 将“结果和当前限制”改为“实验过程与结果”。

## 验收标准

- 全站不再出现“不是……而是……”式句型。
- 学业分数已删除，排名仍保留。
- 研究和实验指标保持不变。
- 防御性结尾和隐私声明已删除。
- 投稿、公开代码和实验条件仍然准确。
- HTML、脚本、内部链接和荣誉一致性检查通过。
