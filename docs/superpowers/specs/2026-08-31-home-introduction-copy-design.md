# 主页个人介绍段落替换设计

## 目标

仅替换主页 `index.html` 中 `#about` 区域的个人介绍段落，不调整全站叙述视角，也不修改其他页面或版式。

## 替换内容

原文：

> 我是合肥工业大学数学学院信息与计算科学专业本科生，目前主要做三维多目标跟踪和轨迹预测。我也做过智能会议系统、Banach 不动点定理推广、ROS 2 激光 SLAM 仿真实验和 RISC-V 计算机视觉验证。

替换为：

> 合肥工业大学数学学院信息与计算科学专业本科生，主要研究方向为三维多目标跟踪与轨迹预测。在理论与工程实践方面均有涉猎，曾参与智能会议系统开发、Banach不动点定理推广研究、ROS 2激光SLAM仿真及RISC-V计算机视觉验证等项目。期待与各位同仁及导师进行深入的学术交流与合作，欢迎随时联系。

新文字必须原样使用，包括技术名词之间的空格形式，不进行额外润色。

## 文件范围

- 修改：`index.html`
- 不修改：其他 HTML 页面、`styles.css`、`script.js`、站点元信息、域名配置

## 验收

1. 主页只出现新介绍，不再出现原介绍。
2. 桌面端和手机端无横向滚动。
3. 介绍段落沿用现有 `.lead` 样式。
4. 站内链接、奖项和研究内容保持不变。
