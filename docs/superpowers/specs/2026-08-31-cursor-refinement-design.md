# 光标样式修正规格

日期：2026-08-31

## 背景

当前桌面端自定义光标使用四向刻度环，视觉上接近十字准星；进入普通文字区域时，自定义光标会隐藏，并恢复浏览器的 I 型文字光标。用户希望光标更简单，并在正文区域保持一致。

## 最终设计

- 采用 A 平衡型：30px 圆环与 5px 中心点。
- 圆环使用 1px 实线，不再绘制四向刻度、十字线或内层圆环。
- 暖纸正文区域使用档案棕；深色资料栏使用明亮陶土棕。
- 普通文字、标题、日期和标签上始终显示自定义圆环与中心点，不切换为 I 型文字光标。
- 悬停链接、按钮和折叠控件时，圆环仍放大至 44px，并保留 HOME、GO、READ、CODE、MAIL 等去向标签。
- 轻量点击印章保持现有行为，不修改 LCX 开场动画、光标跟随速度或移动端布局。

## 响应式与可访问性

- 自定义光标仅在支持精细指针的桌面设备启用。
- 960px 及以下继续使用系统光标，不显示圆环、中心点或点击印章。
- `prefers-reduced-motion: reduce` 下继续禁用自定义光标动效。
- 键盘焦点样式不受影响。

## 实现范围

- `styles.css`：将刻度环改为单实线圆环，删除文字区域隐藏和 I 型光标覆盖规则。
- `script.js`：删除文字目标识别与 `pointer-text` 状态切换。
- `DESIGN.md` 与 `.impeccable/design.json`：同步更新光标组件说明。

## 验收标准

1. 桌面端普通区域显示 30px 圆环和 5px 中心点，不出现十字刻度。
2. 光标经过正文、标题、日期等文字时不消失，也不变为 I 型。
3. GitHub、邮箱、站内详情和导航链接仍分别显示正确的上下文标签。
4. 点击印章仍会在约 420ms 后自动移除。
5. 手机端没有自定义光标，页面无横向溢出。
6. 页面无新增控制台错误。
