# 桌面尺寸、主页信息与荣誉列表修改设计

## 1. 背景与目标

当前网站在桌面浏览器 100% 缩放下整体偏小，用户需要将浏览器调整到 125% 才能获得合适的阅读尺寸。本次修改在保留现有“左侧个人资料栏 + 右侧文档正文”风格的前提下，完成以下目标：

1. 桌面端在 100% 浏览器缩放下具有足够的字号和页面占比。
2. 在主页“研究重点”和“相关兴趣”之后增加“主修课程”。
3. 为智能会议和 Banach 不动点定理推广项目增加准确的详情入口。
4. 将荣誉与竞赛改为逐项展示，并补齐年份和完整名称。
5. 主页与公开 CV 使用一致的奖项信息。

本次不改变现有配色、字体风格、页面动画和侧栏导航结构，也不增加新的奖项或独立项目页面。

## 2. 已确认的设计方向

采用“结构化更新”方案：

- 桌面端对侧栏、正文宽度和显式字号做均衡放大。
- 主页简介信息采用三栏结构。
- 早期研究项目使用现有 Academic research 页面中的独立锚点。
- 荣誉采用“年份 + 奖项全称”的纵向文档列表，不使用卡片和 CSS 分栏。
- 移动端保持单栏，并通过更高的响应式切换点避免窄屏拥挤。

## 3. 桌面尺寸与响应式规则

### 3.1 桌面尺寸

桌面端使用以下目标值：

- 左侧资料栏：`292px`。
- 正文最大宽度：`940px`。
- 正文宽度公式：`min(940px, calc(100% - 88px))`。
- 页面基础字号：`16px`。
- 响应式切换点：`960px`。

显式像素字号同步放大，避免只修改 `body` 后子元素仍保持原尺寸：

- 左侧姓名：`28px`。
- 左侧英文名：`14px`。
- 左侧身份说明：`11px`。
- 左侧资料链接：`10px`。
- 左侧导航：`11px`。
- 正文一级标题最大值：`38px`。
- 正文二级标题：`27px`。
- 正文三级标题：`18px`。
- 首页导语：`17px`。
- 项目正文：`13px`。
- 项目日期：`10px`。
- 项目角色与元信息：`11px`。
- 页面分节标签：`10px`。

页面整体效果应接近当前浏览器 115%—120% 缩放，而不是把所有元素机械放大到 125%。

### 3.2 窄屏与手机端

- 视口宽度不超过 `960px` 时切换为现有移动端单栏结构。
- 移动端正文左右留白保持当前水平，不额外放大。
- 三栏简介信息在移动端按“研究重点、相关兴趣、主修课程”的顺序改为单栏。
- 荣誉条目在移动端将年份置于奖项名称上方。
- 表格、日期和长奖项名称不得造成页面级横向滚动。

## 4. 主页简介信息

`research-lines` 从两栏调整为三栏，宽屏比例为：

```text
研究重点  0.95fr
相关兴趣  1fr
主修课程  1.50fr
```

第三栏内容为：

> 数学分析；高等代数；概率论与数理统计；常微分方程；C 程序设计；C++ 程序设计；数据结构与算法；离散数学；数值分析；初等数论；近世代数；随机过程。

为避免连续一行过长，浏览器可在标点后正常换行，但不得拆分课程名称中的英文或符号。

## 5. 研究项目详情入口

### 5.1 主页入口

在主页两个早期研究条目中分别增加：

- 智能会议：`查看研究项目详情 →`，链接至 `/projects/academic-research.html#meeting-system`。
- Banach 不动点定理推广：`查看研究项目详情 →`，链接至 `/projects/academic-research.html#banach-fixed-point`。

按钮样式复用当前三维运动研究项目的 `inline-links`，不新增按钮组件。

### 5.2 Academic research 页面

现有两个早期研究条目扩展为带固定 `id` 的独立内容单元：

- `meeting-system`
  - 说明项目围绕会议语音转写、模板化纪要生成和人脸考勤展开。
  - 说明用户负责或参与人脸识别考勤、异步图像处理、模型压缩和联邦学习方案设计。
  - 不补写没有材料支持的性能指标、论文或公开仓库。
- `banach-fixed-point`
  - 说明项目属于非线性泛函分析方向。
  - 说明用户参与定理成立条件整理、证明过程推导和论文草稿撰写。
  - 不把论文草稿写成已投稿或已发表成果。

锚点需要考虑固定定位和滚动间距，跳转后标题不能紧贴浏览器顶部。

## 6. 荣誉与竞赛

### 6.1 展示方式

- 标题使用 `Honors and awards`。
- 每项奖项独立成行，不合并“优秀共青团员”和“优秀共青团干部”。
- 桌面端为“年份列 + 完整名称列”。
- 按年份从新到旧排序，同一年按重要性和确认顺序排列。
- 主页和 `resume.html` 使用完全相同的 9 项内容与顺序。
- 不在本次修改中加入履历目录中的英语竞赛、职业规划、军训或其他奖项。

## 7. 文件范围

预计修改：

- `styles.css`：桌面比例、显式字号、三栏简介、荣誉纵向列表和响应式规则。
- `index.html`：主修课程、两个研究详情入口、9 项荣誉。
- `projects/academic-research.html`：两个早期项目的锚点与详情文字。
- `resume.html`：9 项荣誉及打印版结构。

不修改实习详情页、Notes 页面、脚本动画逻辑、站点域名配置和 GitHub Pages 发布方式。

## 8. 验收与测试

### 8.1 桌面端

在浏览器 100% 缩放下检查：

- `1366 × 768`
- `1440 × 900`
- `1920 × 1080`

每个尺寸必须满足：

- 左侧资料栏完整可读。
- 正文不显得过小，也不与侧栏发生重叠。
- 页面无横向滚动。
- 三栏简介信息保持清晰层次。
- 荣誉完整名称正常换行，年份不被拆分。

### 8.2 手机端

在 `390 × 844` 下检查：

- 页面无横向滚动。
- 三栏信息按单栏顺序显示。
- 奖项年份和全称均可完整阅读。
- 移动菜单和现有动画仍能正常使用。

### 8.3 功能与内容

- 两个新增详情链接分别跳转到正确锚点。
- 锚点跳转后的标题位置可见。
- 主页和 CV 的 9 项奖项文字、年份和顺序完全一致。
- CV 打印预览中荣誉列表不重叠、不截断。
- 所有内部链接目标存在。
- 浏览器控制台没有新增错误。

## 9. 非目标

- 不建立奖项证书图片画廊。
- 不把荣誉改成卡片、徽章墙或 PPT 式展示。
- 不新增早期研究项目的独立 HTML 页面。
- 不增加未经确认的课程、奖项、论文、指标或 GitHub 链接。
- 不重新设计配色、字体体系和页面动画。
