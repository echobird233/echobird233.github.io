# 国家奖学金答辩材料同步设计

## 目标

以《卢春翔国家奖学金答辩》PPT 中已经整理的事实为依据，补充个人网站的学业、科研、大创、实习和获奖信息，同时保持首页简洁、详情页完整、不同页面之间表述一致。

## 信息来源与优先级

1. 用户在当前对话中直接确认的信息优先级最高。
2. 答辩 PPT 用于补充尚未公开或表述不完整的信息。
3. 网站现有内容在与前两项不冲突时保留。
4. 不根据简称推测竞赛全称、年份、级别或奖项名称。

因此，“挑战杯”继续采用用户此前确认的“2026 年‘挑战杯’大学生创业计划竞赛校级二等奖”，不使用 PPT 中的“校级三等奖”。

## 内容范围

### 首页

- 在个人简介或紧邻简介的位置补充大二学年总成绩 95.07 分、专业第一、年级第一的信息。
- 保持首页研究条目为摘要，只更新两项研究的真实进展，不堆叠实验细节。
- 在荣誉列表中增加“2025—2026 学年本专科生国家奖学金”。
- 增加 PPT 中能够准确命名的竞赛奖项；名称或年份不充分的项目不擅自扩写。

### CV

- 在教育背景中补充大二学年总成绩、专业排名与年级排名。
- 更新三项大学生创新训练项目的结项或主持状态。
- 更新两项三维运动研究的论文与代码状态。
- 更新实习项目说明。
- 同步新增荣誉与国家奖学金。

### 学术研究详情页

- 将轨迹预测项目的完整中英文题目写入详情页。
- 说明稿件由独立第一作者完成，曾投稿 `Vehicles`，当前正在补充实验并准备重投。
- 添加公开 Zenodo DOI：`https://doi.org/10.5281/zenodo.22264823`。
- 将 VeloODE-MOT 的完整中英文题目写入详情页。
- 说明稿件由独立第一作者完成，计划完善实验后投稿 IEEE Robotics and Automation Letters，代码目前位于 GitHub 私有仓库。
- 将智能会议系统和 Banach 不动点定理推广项目标记为已结项；不写成已发表论文或已发布软件。

### 实习详情页

- 保留上海苦芽科技有限公司、线上实习和起始日期等现有信息。
- 补充 ROS 2 激光 SLAM 项目中仿真环境搭建、坐标变换与导航数据检查、仓库路线设计以及地图、路径和日志记录等工作。
- 保留 Pixi RISC-V 支持验证项目，不因 PPT 重点介绍 ROS 2 而删除网站已有且已经确认的信息。

## 明确排除

以下内容不加入网站：

- 学生工作和任职经历；
- 入党发展经历；
- 社会实践及其表彰；
- 志愿服务经历、活动和服务时长。

与上述范围直接相关的表彰也不进入荣誉列表。

## 文案与结构原则

- 首页使用简短、平铺的事实陈述；详细背景放到 CV 或项目详情页。
- 论文状态必须区分“曾投稿”“准备重投”“计划投稿”和“尚未发表”。
- 不把项目草稿写成正式论文成果，不把私有仓库写成公开代码。
- 继续使用网站现有时间线、开放式条目和荣誉列表，不增加新的卡片式布局。
- 保持中文全角标点、年份连接号和英文期刊名称的一致性。

## 验收标准

- 首页、CV、研究详情页和实习详情页之间不存在状态矛盾。
- 首页新增 2025—2026 学年国家奖学金。
- Zenodo DOI 可点击并指向正确地址。
- 所有新增信息均能追溯至用户直接确认或答辩 PPT。
- 排除项没有出现在网页正文或荣誉列表中。
- HTML 结构检查、脚本语法检查和链接检查通过。
