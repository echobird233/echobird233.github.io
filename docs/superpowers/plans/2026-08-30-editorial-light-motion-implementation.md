# 「编辑之光」动效实施计划

日期：2026-08-30  
依据：`docs/superpowers/specs/2026-08-30-editorial-light-motion-design.md`

> `writing-plans` 技能在当前会话中不可用，因此使用本项目内的等价实施清单。

## 目标

将已批准的 C2「编辑之光」方案应用到整个静态 GitHub Pages 网站，保留现有内容真实性、内部路由、公开仓库链接、移动端与打印能力。

## 任务 1：重构全局视觉系统

文件：`styles.css`

- 将桌面布局改为浏览器左边缘的 270 px 深色固定身份栏；
- 将右侧正文限制在约 820 px，并保持文档式密度；
- 增加墨迹 LCX、活动导航线、阅读进度、背景点阵、聚光、抽线链接和条目悬停样式；
- 为首页陈述、章节标签和分隔标题增加样式；
- 更新移动端与打印样式；
- 增加 `prefers-reduced-motion` 完整降级。

## 任务 2：实现原生交互控制器

文件：`script.js`

- 保留移动端菜单与打印按钮；
- 注入载入幕布、阅读进度、聚光与自定义光标；
- 使用 `IntersectionObserver` 处理滚动揭示与首页章节高亮；
- 为研究、经历和笔记条目增加受控的轻微倾斜；
- 为同域非锚点链接增加短页面切换动画；
- 仅在精确指针且未开启减少动态效果时启用高成本交互；
- 防止无 JavaScript 情况下内容隐藏。

## 任务 3：调整首页首屏语义

文件：`index.html`

- 在 About、Research、Experience、Honors 添加章节编号标签；
- 将首页 `About` 标题替换为获批研究陈述；
- 保留简介、研究重点、相关兴趣、时间线、实习与荣誉内容；
- 不修改成果状态，不新增不存在的仓库链接。

## 任务 4：统一子页面的进入层次

文件：

- `projects/academic-research.html`
- `projects/internship.html`
- `resume.html`
- `articles/index.html`
- `404.html`

- 为各页面首节增加简短英文编号或类别标签；
- 保留当前 `aria-current`；
- 确认所有页面继续加载统一的 `styles.css` 与 `script.js`；
- 404 页面不启用章节滚动逻辑，但保留基础载入与链接反馈。

## 任务 5：静态检查

- 运行 `git diff --check`；
- 搜索第三方 CDN、远程字体和意外依赖，确认没有新增；
- 检查所有本地 HTML 文件中的内部 `href` 目标存在；
- 检查重复 `id` 与缺失的导航目标；
- 检查两条公开 GitHub 仓库链接仍在；
- 检查论文草稿仍标注尚未投稿。

## 任务 6：浏览器验证

- 桌面端：首页首屏、固定左栏、聚光、自定义光标；
- 桌面端：滚动后当前章节和阅读进度变化；
- 桌面端：Research、Experience、Notes、CV 和 404 页面；
- 移动端：身份区、菜单、正文单栏和无横向溢出；
- 减少动态效果：内容默认可见且无持续动画；
- 打印：CV 中隐藏身份栏和装饰元素。

## 任务 7：提交与发布

- 提交所有已验证的网站修改；
- 推送到 `origin/main`；
- GitHub Pages 部署完成后，再检查公开网址及自定义域名。
