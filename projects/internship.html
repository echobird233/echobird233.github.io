PROJECT 01 · ROS 2 / SLAM

ROS 2 激光 SLAM 调研与复现实验

项目以 ROS 2 Jazzy、Gazebo Harmonic、RViz2、Nav2 与 slam_toolbox 为工具链，使用 TurtleBot3 在仿真室内环境中完成从建图到导航的验证闭环。

完成内容

  • 搭建 TurtleBot3 仿真与自定义室内环境。
  • 完成在线二维激光建图、地图保存和 RViz2 可视化。
  • 验证 Nav2 导航目标，整理路径、覆盖率与实验日志。
  • 对不同场景的结果进行对比，记录扫描畸变和路线差异等限制。
项目边界：该项目聚焦 2D LiDAR SLAM 与导航复现，不将其包装为三维 SLAM 或真实机器人部署结果。

PROJECT 02 · RISC-V / VISION

Pixi RISC-V 支持验证与计算机视觉应用

项目围绕三个问题展开：Pixi 能否在 RISC-V 环境中运行，RISC-V 是否能够承载有意义的 AI 推理，以及 Pixi 的任务编排能否帮助组织验证流程。

环境与方法

  • 环境：QEMU RISC-V + Ubuntu 24.04，Pixi 0.73.0。
  • 组合：在 linux-riscv64 生态限制下采用 APT + Pixi 任务系统。
  • 验证：Lucas–Kanade 光流与 ONNX CNN 推理管线。

实验记录
